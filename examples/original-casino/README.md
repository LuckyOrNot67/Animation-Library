# Exemples originaux de casino

Générés intégralement par src/create-demo.js : silhouettes géométriques, textures, rigs et timelines. Aucun asset d’un jeu tiers n’est repris. Références techniques simples : coin-burst, wild-symbol, bonus-gem, avec cinq actions chacune. Modifier le générateur, lancer npm run create:demo puis npm run learn.
