# rr2_background

Machine : red-robin. Format : spine-skel. Version : 4.2.43.

Le skeleton contient le rig et toutes les actions. actions/ expose les timelines de chaque action. pieces/ contient les découpes des textures ; metadata.json relie les régions aux pages et sources.

- Skeleton binaire : liste des actions lisible dans le runtime, timelines non extraites.
- Aucun atlas associé : aperçu Spine indisponible, sources conservées.
