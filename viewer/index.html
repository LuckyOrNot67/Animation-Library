Animation Library /

CAPTURER · CLASSER · COMPRENDRE

Des captures brutes aux animations lisibles.

Une bibliothèque de références pour explorer les rigs, les actions et les images qui composent chaque personnage ou effet.

01 / Déposer

Dépose directement gatorhunters2.har dans reception/. Le nom du fichier devient celui de la machine. Exporte le HAR avec le contenu des réponses. Tu peux aussi déposer des HAR ou des fichiers décompressés dans un dossier par machine.

02 / Construire

Lance npm run build (Windows : npm.cmd run build). Les fichiers visuels reconnus sont regroupés dans bibliotheque/. Tes sources restent intactes.

03 / Étudier

Choisis une machine, un personnage ou un effet, puis une action. Explore les textures, les pièces et les timelines JSON.

Ce que contient un package

Le skeleton définit les os, les slots, les skins et les mouvements. L’atlas indique où se trouvent les pièces dans les textures. Les PNG extraits rendent ces pièces faciles à examiner. Les actions partagent le même rig et ses textures.

Tri et nettoyage

Les scripts, textes et fichiers non visuels ne sont pas copiés dans la bibliothèque. Le manifest liste ce qui a été écarté. Les visuels sans association restent dans autres/. Les versions Spine, textures absentes et associations incertaines sont signalées.

Le lecteur Spine charge son runtime depuis Internet. Un atlas et ses textures sont nécessaires pour l’aperçu. Les autres formats restent consultables comme sources.
